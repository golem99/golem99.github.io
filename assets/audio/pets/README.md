# Djurljud

Steve laddade ner dem från Pixabay 2026-10-09. Pixabays licens gäller: fria att använda, inget krav på namnangivelse. Claude har klippt dem och jämnat ut ljudstyrkan med ffmpeg.

| Fil | Källa (inkorgen) | Används när |
|---|---|---|
| `dog-bark-happy.mp3` | `yodguard-friendly-small-dog-bark-1-535470.mp3` | man klappar valpen eller den får mat |
| `dog-yip-puppy.mp3` | `magiaz-baby_dog_barking-457713.mp3`, 0–1,05 s | glad, omväxlande |
| `dog-bark-single.mp3` | `dragon-studio-dog-bark-494308.mp3` | den hämtar bollen, eller någon hälsar ute |
| `dog-whine.mp3` | `magiaz-dog_cry-385758.mp3`, 0,75–2,95 s | den är hungrig |

Katten (mjau och spinn) görs fortfarande i ljudmotorn (`src/presentation/audio/synth.ts`).
