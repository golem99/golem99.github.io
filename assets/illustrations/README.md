# Godkända samtalsbilder

Lägg färdiga PNG/WebP/JPG här, med filnamnen från bildbibelns PDF. Lägg sedan till en post i catalog.json, exempelvis:

```json
{ "assets": [
  { "id": "DLG-ARVID-COR-HELLO", "src": "/assets/illustrations/love_dlg_arvid_cor_hello.png" },
  { "id": "POR-ARVID", "src": "/assets/illustrations/love_por_arvid.png" }
] }
```

Katalogen innehåller granskade leveranser. Bild-ID motsvarar person, plats och känsla. En annan karaktär eller plats används aldrig som reserv. POR-bilder fungerar som neutrala reserver. Saknade eller trasiga bilder faller tillbaka till det ursprungliga porträttet.

SCN, COVER, MOD, EXP och LOC är produktions-ID men registreras ännu inte i denna samtalskatalog. De fem berättelseförloppen väljer nu bild utifrån den faktiskt hörda repliken och valt svar. SHY används vid uttalad nervositet/pirr, aldrig från dolda relationsvärden. Vänskap och utrymme ger inte ett romantiskt bildsvar. Förvara originalen separat; inget genereras vid spelkörning.

Andra bildgenomgången väntar tills Steve levererat hela serien. Anteckna likartade uttryck i granskningen, men begär inte löpande omgenereringar. Nuvarande PNG-filer är oförändrade kopior av originalen; webboptimering återstår.
